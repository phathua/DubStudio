# Model evaluation candidates

These are candidates, not recommendations verified on DubStudio. We do not yet download or run local models. Resource requirements depend on model version, runtime, quantization, operating system and input. Inspect each checkpoint and voice license before distribution or use.

| Task                | Candidate                                                                                                                                                                    | Notes                                                                                                         |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Speech recognition  | [whisper.cpp](https://github.com/ggml-org/whisper.cpp)                                                                                                                       | CPU/Metal and other backends; word-level timestamps are experimental.                                         |
| Speech recognition  | [faster-whisper](https://github.com/SYSTRAN/faster-whisper)                                                                                                                  | Word timestamps; CPU INT8 and NVIDIA CUDA; upstream benchmarks are not minimum requirements.                  |
| Speech recognition  | [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)                                                                                                                         | Assess languages, timestamps and license per checkpoint.                                                      |
| Speaker diarization | [pyannote community-1](https://huggingface.co/pyannote/speaker-diarization-community-1)                                                                                      | Local use after downloading; acceptance of conditions and account token required.                             |
| Translation         | [M2M100 418M](https://huggingface.co/facebook/m2m100_418M)                                                                                                                   | Multilingual local candidate; benchmark all target language pairs.                                            |
| Translation         | [NLLB-200 600M](https://huggingface.co/facebook/nllb-200-distilled-600M)                                                                                                     | Non-commercial weights license; show restrictions explicitly.                                                 |
| Translation         | [Gemma 4 via Google AI Studio](https://ai.google.dev/gemini-api/docs/interactions-overview)                                                                                  | Online: user-initiated only. Provider terms, quotas and pricing apply.                                        |
| TTS                 | [Piper voices](https://github.com/rhasspy/piper/blob/master/VOICES.md)                                                                                                       | Includes Vietnamese, English and Chinese voices; evaluate license per voice and runtime.                      |
| TTS                 | [VieNeu-TTS](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo-GGUF)                                                                                                     | Vietnamese candidate with CPU/CUDA builds; file size is not memory usage.                                     |
| TTS                 | [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)                                                                                                                             | Includes Korean, Chinese and English; Vietnamese is not listed.                                               |
| TTS                 | [Gwen-TTS](https://huggingface.co/g-group-ai-lab/gwen-tts-0.6B), [XTTS](https://github.com/coqui-ai/TTS)                                                                     | Validate language support, resources, model and runtime licensing.                                            |
| Separation          | [Demucs](https://github.com/facebookresearch/demucs), [MDX23](https://github.com/ZFTurbo/MVSEP-MDX23-music-separation-model), [Spleeter](https://github.com/deezer/spleeter) | Evaluate actual dialogue/music/effects and each checkpoint license. Artifacts and distortion remain possible. |

Benchmark CPU, peak RAM and VRAM, disk use, timing and quality on both macOS and Windows. Do not infer an 8 GB machine can run every candidate from model file size.
