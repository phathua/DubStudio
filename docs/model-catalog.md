# Experimental model inventory

`scripts/model_catalog.json` indexes the model families mentioned in the supplied list; it is a research inventory, not an executable model registry. Entries may represent families or multiple checkpoints. `null` means unknown, not zero. Requirements from the supplied list are not treated as measured minimums: RAM and VRAM depend on checkpoint, runtime, precision, OS and input. No listed model is integrated with the app's model manager. The Python assessment does not download or execute models and `no_known_conflict` does not mean compatible, licensed for every use, installed, or recommended.

```sh
python3 scripts/model_catalog.py --category tts --language vi --ram-gb 8 --commercial
```

Each result reports `incompatible` only for an identified conflict, `unverified` where requested evidence is missing, and `no_known_conflict` where the requested checks found none. For CPU omit `--vram-gb`; it does not establish CPU support. Outputs include unverified entries so they are not silently discarded. Model licensing is separate from runtime/code licensing and must be checked per exact checkpoint and voice before distribution or commercial use. Gender and voice lists in the supplied notes have not been independently validated and are not represented as facts.

Sources for the checked fields include [Qwen3 ASR and aligner language support](https://huggingface.co/docs/transformers/main/en/model_doc/qwen3_asr), [Piper's voice list](https://github.com/rhasspy/piper/blob/master/VOICES.md), [Kokoro model card](https://huggingface.co/hexgrad/Kokoro-82M), [VieNeu-TTS v3 Turbo model card](https://huggingface.co/pnnbao-ump/VieNeu-TTS-v3-Turbo), [NLLB model card](https://huggingface.co/facebook/nllb-200-distilled-600M), and [Demucs's upstream discussion of weights](https://github.com/facebookresearch/demucs/issues/327). Some code repository URLs are starting points for further research, not evidence about the weights. The Qwen aligner does not list Vietnamese among its 11 supported languages, even though Qwen ASR does. An official approximate VRAM table for Whisper is documented [upstream](https://github.com/openai/whisper#available-models-and-languages), but it is not a tested minimum for DubStudio's runtimes and does not justify a hard lock.

## Choosing models after measurement

The inventory does not currently rank or automatically select a model. The available local tests are not a controlled comparison across checkpoints, languages, workloads, and machines, so they are insufficient for a general ranking or a hardware lockout. A future benchmark should record the exact checkpoint and version, checksum, inference backend and precision, operating system, CPU, GPU, RAM and VRAM, input language and duration, and reproducible dataset. Measure peak process RAM and GPU memory, runtime and real-time factor, download and cache size, failure rate, and task-specific quality (for example transcription/word timing accuracy or separation artifacts). Compare only matching tasks and languages, label results by machine and workload, and remeasure when the runtime or model changes. Measurements guide recommendations; insufficient or missing evidence remains explicitly unknown.
